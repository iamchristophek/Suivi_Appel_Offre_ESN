# Suivi_Appel_Offre_ESN
 Le rapport suit les besoins associés aux appels d'offres, leur statut commercial et le délai de réponse envoyée aux achats. Le délai cible est de **5 jours ouvrés**.  **Une ligne de Données représente un besoin.** Plusieurs besoins peuvent porter le même DAH : ces répétitions sont normales et doivent rester comptées.
